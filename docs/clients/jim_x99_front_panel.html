Front Panel Pins — X99 Dual-Socket

Your board is an X99 dual-socket (LGA 2011-3) motherboard — the type sold under brands like Machinist, Jginyue and Huananzhi. Its front panel header uses the standard Intel 9-pin layout. Here's exactly where everything goes.

Where each wire goes

Your case wires → header pins

🔘 Power Switch NO POLARITY

Case wires: PWR SW / PW / Power On (usually a 2-pin block, often green/white or black/white).

  • Plug onto pins 5 + 7 (top row). Either orientation works — it's just a momentary short.

🔁 Reset Switch NO POLARITY

Case wires: RESET SW / RST / RES (2-pin block, usually blue/white).

  • Plug onto pins 6 + 8 (bottom row). Either orientation.

💡 Power LED POLARITY MATTERS

Case wires: PWR LED + / − (2-pin block; colored wire = +, white = −).

  • ＋ wire → pin 1, − wire → pin 3 (top row).
  • If the LED doesn't light, flip the block — no harm done.

💾 HDD LED POLARITY MATTERS

Case wires: HDD LED + / − (2-pin block; colored = +, white = −).

  • ＋ wire → pin 2, − wire → pin 4 (bottom row).

🔊 Speaker (if your case has one)

These boards usually don't route a chassis speaker pin — the beeps come from the debug LED display instead (see below).

One caution: these X99 dual-socket boards occasionally vary the top/bottom row order between batches. The silkscreen on the PCB prints the pin names right next to the header (usually PWRBTN, RST, HDLED, PWRLED) — if a label differs from this diagram, follow the silkscreen. The layout above is what this board model ships with 95% of the time.
Also useful

Powering & booting this board

⚡ Power supply rules CRITICAL

  • 24-pin ATX main power — right edge.
  • BOTH 8-pin CPU (EPS) cables must be plugged in — one per socket. With only one connected, the board won't POST properly.

🧠 RAM rules

  • 8 slots total, 4 per CPU — DDR4 (ECC REG or desktop RAM).
  • Distribute equally between both CPUs; each CPU needs at least one stick in its primary slot or you'll stop at a memory POST code (b7 / 53).

🖥️ Debug LED codes

  • FF / AA / A3 — booted, normal.
  • b7 / 53 / 67 — RAM issue (reseat / swap sticks).
  • 00 / 19 — CPU init error (check socket pins + both 8-pin cables).

✅ Bottom line

Power button → pins 5+7 · Reset → 6+8 · PWR LED → 1+3 · HDD LED → 2+4. When in doubt, the missing pin 10 is your compass, and the silkscreen labels on the board are your final authority.
